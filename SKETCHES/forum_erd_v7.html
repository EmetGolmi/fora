v7 Changes — UK & City-State Schema Resolution
CRIT Jurisdiction: added government_type enum (adds geographic_only value — England has a boundary but no government layer). Added status enum (active · suspended · dissolved · pending) + suspended_since date nullable + suspension_reason text nullable. Enables NI Assembly collapse modeling and any suspended legislature globally.
CRIT Office: 5 new fields. concurrent_holders_required integer default 1 — UI contract: always render this many active Terms. holder_balance_rule enum (none · opposing_parties · community_designation · proportional · reserved_community). investiture_dates date[] nullable — fixed changeover dates (San Marino Apr 1 / Oct 1). role_derived_from_office_id FK→Office nullable — Andorra co-prince derives from French President office; cascade on source term end. living_regency boolean default false — Liechtenstein: Hans-Adam II sovereign but Alois holds operational authority.
CRIT Person: added community_designation enum nullable (unionist · nationalist · other · not_applicable). Formal constitutional category used in Stormont power-sharing validation — NOT a political opinion field. Stored structurally; displayed only in NI Assembly context.
BREAK CivicBody: jurisdiction_id (single FK) replaced by jurisdiction_ids uuid[]. Breaking change. Required for GFA North/South Implementation Bodies (Waterways Ireland etc.) which span UK + Republic of Ireland. Also covers US interstate compacts and British-Irish Council. Single-jurisdiction bodies store a one-element array — no functional regression for existing data.
SEM Action (future Bill entity): added territorial_scope enum (uk_wide · england_only · england_wales · england_wales_ni · scotland_only · wales_only · ni_only · devolved_varies). Drives address-based legislation filtering — Manchester address resolves England-only bills correctly without a separate English parliament record.
SEM Jurisdiction system_type enum: added crown_dependency (Jersey, Guernsey, Isle of Man — not UK sub-jurisdictions, not sovereign states; Crown handles defense/foreign affairs).
HYG England modeled as Jurisdiction with government_type: geographic_only — has boundary, no Offices. Resolves West Lothian address lookup gap without creating a phantom English parliament.
HYG Westminster Parliament modeled as one Office under UK Jurisdiction with territorial_scope: uk_wide. English-only legislation gets territorial_scope: england_only — same body, scoped output. No institution split.
v6 Changes (carried forward)
CRIT CivicBody fully specced — 20 fields. CivicBodyTag join table added.
CRIT Term: office_id nullable + civic_body_id FK added. CHECK: exactly one of office_id / civic_body_id NOT NULL.
SEM AddressLookup: civic_body_ids uuid[] promoted from pending to active.
