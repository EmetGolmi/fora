Hardcoded Exceptions

Stored in Jurisdiction.hardcoded_config as JSON. Nebraska: chambers: 1. DC: senate_seats: 0, house_delegate: non_voting. States with appointed AG: ag_elected: false. Territories: federal_voting: false. Write once, test once, never changes unless there's a constitutional amendment.

Phase 6 Stubs (Built Now)

Contribution table already has tone_score, source_tier, cohort_tags, and steelman_seen columns — empty in Phase 1, populated in Phase 6. No migration needed later. User table has trust_level and friction_exempt ready for the discourse layer.

DataAlert System

Every official card has a live display_status driven by OfficeStatus. When a Term expires, an alert fires automatically. Three community flags triggers review. Source conflicts mark a card DISPUTED — both values shown to users. The platform never silently shows wrong data; it shows uncertain data honestly with a dot color and tooltip. Sync frequency varies by layer: federal daily, state weekly, local monthly, special districts ad hoc.

Identity Model

Real identity (name, email, address) is encrypted at rest and never surfaced publicly. The public persona is constructed from public_occupation + public_age_range + public_region. Displayed as: "Nurse · 40s · Northern Virginia". Address is hashed for district lookup — the raw string is never stored.
