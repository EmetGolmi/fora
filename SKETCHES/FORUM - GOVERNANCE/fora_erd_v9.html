⚖ CARE Principles — Indigenous Data Sovereignty (applied to §9 Language & Recording)
C
Collective Benefit
Data ecosystems must serve the collective needs of Indigenous communities. Tribal language data benefits the community, not only researchers or the platform.
A
Authority to Control
Tribes govern their own data. LanguageSteward role = formal tribal appointment. Tribes can withdraw all data at any time. FORA is custodian, not owner.
R
Responsibility
FORA has a responsibility to share data in ways that strengthen tribal sovereignty. Recordings of elders are treated as irreplaceable archival heritage.
E
Ethics
Minimizing harm to Indigenous peoples. access_level on CivicRecording is set by the tribe. Critically endangered language recordings have heightened access controls.
v9 Changes — Civic Identity Marker, Five-Tier Source System, Sponsorship
CRIT Source: quality_tier enum (S/A/B/C/D/⚠) retired. Replaced by tier enum (institution · verified · perspective · cautioned · disputed) — five named tiers by relationship to the civic record. Soccer card logic: cautioned = yellow card (flag raised, play continues); disputed = red card (community upheld, credibility compromised). FORA never deletes sources — disputed sources remain in archive with full public audit log.
NEW Source: +card_state enum (standard · bare) — bare card treatment for tiers 4–5 (no container). +flag_count integer — community flag count. +flag_audit_log jsonb — public record of who flagged, what evidence, how reviewed, when decided.
CRIT User: +civic identity marker fields. credential_abbr string — pill text (PE, ESQ, eng, bartender; null = anonymous). credential_verified boolean — gold ring on/off. Verified = state licensing board confirmed. No ring for self-reported. contribution_score integer 0–1000 — quality-based, recalculated nightly, cannot be gamed by volume.
NEW User: +marker_face enum — what renders in the circle (abbreviation · generated · custom_image). +veteran_branch enum — drives ribbon bar color. null for active military (participate as anonymous citizens). +service_distinguishers string[] — judge · fire · leo · ems · former_elected · civic_body. +former_elected_count integer — drives gold star count (max 3). +active_sponsorship_id → Sponsorship.
NEW §4 CredentialVerification — lifecycle entity for all verification types: professional_license (state API), dd214 (NPRC API), court_roster, election_record, civic_appointment, ems_cert, fire_cert, post_cert. Status: pending → verified → lapsed. Quarterly recheck. Lapsed status removes gold ring automatically.
NEW §4 Sponsorship — Sadie Hawkins rule enforced at schema level: initiated_by enum (user) — only the user can initiate. Sponsor sets cohort eligibility criteria; user browses and selects. disclosed boolean default true — cannot be set false. monthly_rate_cents is public. Platform cut 18%. No cap at schema level — community sees all values, transparency is the regulator.
NEW §4 Sponsor — company registry. category enum: civic_institution/union pay no platform fee; commercial pays full fee. no_influence_acknowledged boolean — must be true before approval. Sponsors cannot condition payment on positions taken. approval_status with public decision log.
HYG Active military policy: active service members have no veteran_branch or service_distinguishers set. They participate as anonymous citizens. DoD Directive 1344.10 compliance — platform does not create structural markers identifying active service members in civic discourse context.
