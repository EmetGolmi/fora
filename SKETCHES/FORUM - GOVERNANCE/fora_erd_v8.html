⚖ CARE Principles — Indigenous Data Sovereignty (applied to §9 Language & Recording)
C
Collective Benefit
Data ecosystems must serve the collective needs of Indigenous communities. Tribal language data benefits the community, not only researchers or the platform.
A
Authority to Control
Tribes govern their own data. LanguageSteward role = formal tribal appointment. Tribes can withdraw all data at any time. FORA is custodian, not owner.
R
Responsibility
FORA has a responsibility to share data in ways that strengthen tribal sovereignty. Recordings of elders are treated as irreplaceable archival heritage.
E
Ethics
Minimizing harm to Indigenous peoples. access_level on CivicRecording is set by the tribe. Critically endangered language recordings have heightened access controls.
v8 Changes — Language, Translation & Indigenous Civic Infrastructure
NEW §9 Language & Recording — 7 new entities: CivicLanguage, Translation, TranslationVote, CivicRecording, CivicTranscript, TranscriptSegment, LanguageSteward.
CRIT Jurisdiction: +civic_languages string[] — ordered pair of ISO 639-3 codes defining the display language pair for this jurisdiction. Index 0 is always the primary civic language; index 1 is the paired secondary. EN omitted for jurisdictions where EN is primary; always present as index 0 for US/UK/CA/AU. Examples: ["en","es"] Cuba · ["en","de"] Germany · ["en","fr"] Canada · ["en","ar"] UAE · ["en","nav"] Navajo Nation.
CRIT Jurisdiction: +data_sovereignty_tier enum — standard · indigenous_care · watch · restricted. indigenous_care tier activates CARE principles enforcement: withdrawal rights, steward-gated translations, heightened recording access controls.
SEM CivicLanguage: master registry. rtl boolean drives layout flip for Arabic (UAE). endangerment_status (UNESCO scale) gates public crowdsourcing — critically_endangered languages require LanguageSteward approval for all contributions.
SEM Translation: every user-facing string in the platform is translatable. source enum: ai_generated · community_submitted · steward_approved · official. AI ships first; community replaces; steward approves for indigenous_care jurisdictions.
SEM CivicRecording: audio record of tribal gatherings. access_level set by tribe — not FORA. pipeline_stage tracks recording → transcription → transliteration → structured civic items. Audio is the primary record; text is derived.
SEM CivicTranscript + TranscriptSegment: time-aligned transcript. Click any segment line → audio jumps to that moment. Speaker identification (elder vs council member vs public) stored per segment. Segment confidence score for AI-generated segments.
SEM LanguageSteward: formal role appointed by tribal government. Scope controls what they can approve: translations · recordings · both. Required for any indigenous_care jurisdiction before language content goes live.
HYG Translation crowdsourcing for tribal languages is not public. CivicLanguage.public_crowdsource_enabled boolean. Set false by default for all languages with endangerment_status endangered or worse. FORA surfaces contribution UI only to authenticated users with tribal affiliation signal or steward role.

CivicLanguage
new v8
PKiduuid
IDXiso_639_3string (nullable)
Standard code where it exists. Nullable — some tribal languages lack assigned ISO codes. Non-standard codes use fora_{name} prefix e.g. fora_lakota.
—endonymstring
Name in the language itself. "Diné Bizaad" not "Navajo". "Deutsch" not "German". "Gaeilge" not "Irish". "ᏣᎳᎩ" for Cherokee (syllabary script).
—exonym_enstring
—scriptenum
latin · cherokee_syllabary · arabic · devanagari · cyrillic · han · hebrew · georgian · armenian · latin_romanized · other
—rtlboolean default false
⚠ RTL = true for Arabic (UAE), Hebrew, Urdu. Drives full layout mirror on bilingual display. Must be in design system from day one — retrofit is painful.
—endangerment_statusenum
UNESCO scale: safe · vulnerable · definitely_endangered · severely_endangered · critically_endangered · dormant · awakening
⚖ critically_endangered → public_crowdsource_enabled forced false. All contributions require LanguageSteward approval regardless of user affiliation.
—public_crowdsource_enabledboolean default true
Set false by default for endangered, severely_endangered, critically_endangered. Contribution UI hidden from public; visible only to authenticated users with tribal affiliation signal or steward role.
—has_standard_orthographyboolean
Some tribal languages have contested or multiple orthographies. When false, CivicTranscript.orthography_notes field becomes required.
