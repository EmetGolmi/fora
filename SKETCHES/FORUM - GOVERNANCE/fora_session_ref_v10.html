hero-right · net-label · chip variants

52×34px img · border 0.5px rgba white · border-radius 2px
Organization flag/emblem sits in the identity slot (Option A) — same position and scale as a national flag. Displayed with a faint white rule border. Right of it: endonym + entity name. Applied to Hezbollah (yellow/green flag) and Quds Force (blue/gold flag). Pattern generalizes to all NGE pages: every entity has a visual mark at this slot.
NEW v9
Wellbeing Survey Prompt
wellbeing_pending state · "Rate it ›" amber display
When no FORA-native WellbeingSnapshot exists for a jurisdiction, the Freedom and Happiness stat slots show "Rate it ›" in amber instead of a dash. Clicking opens the Cantril Ladder or civic freedom survey. First contributor seeds the score. confidence_tier: seed → emerging → community → statistically_meaningful → robust. Sub-national jurisdictions (state, city, neighborhood) start in pending state; national scores are seeded from Freedom House / WHR imports.
NEW v9
7-Tab Structure + Hover Questions
tabs-inner · tab[title] · ::after tooltip
Universal 7 tabs for all jurisdictions: Overview · Active Crisis ● · Government · Foreign Affairs · Doctrine & History · Discourse · The Record. Each tab has a title= attribute with the civic question shown on hover via CSS ::after tooltip. Questions: "What is this place?" / "What is happening right now?" / "How is it governed?" / "How does it relate to the world?" / "What does it believe?" / "What is contested?" / "What is the record?" Active Crisis is conditional — dot appears only when crisis_active=true.

Locked Decisions
Architectural and design decisions made this session that are not to be revisited without explicit discussion.
DecisionWhat was decidedStatus
NEWHero stat order
Population → Freedom → Happiness → GDP/Budget → Currency/USD. Locked for all jurisdiction scales. HDI removed from hero. States drop currency. Cities drop currency. Neighborhood orgs show members + active efforts.Locked
NEWTicker replaces static alert
The war-alert static div is replaced by a scrolling ticker bar whenever crisis_active=true. The ticker carries war-specific data (day counter, oil, Hormuz, ceasefire status, etc.) that formerly cluttered the hero stats. Non-crisis jurisdictions get a quiet-ticker — a static one-liner in #0e1a2e.Locked
NEWFreedom + Happiness at all scales
Freedom and Happiness are FORA's primary measurement mission, not just display stats. National scores seeded from Freedom House + World Happiness Report. Sub-national scores built bottom-up from user contributions via WellbeingContribution entity. The dash at sub-national scale is replaced by "Rate it ›" survey prompt. This is FORA's original data contribution — the first systematic Freedom and Happiness index at neighborhood scale.Locked
NEWRaster vs. vector governance
FORA needs two parallel governance models. Raster (Westphalian): territory-bounded, every address belongs to one sovereign. Vector (nodal/tribal/communal): people-bounded, authority attaches to communities not coordinates. GovernanceModel entity in ERD v13+ encodes this. Iran is hybrid. Hezbollah, Houthis, Kurds, Catholic Church are vector. Sykes-Picot imposed raster logic on vector-organized societies — sykes_picot_imposed boolean flags this.Locked
NEWNGE emblem — Option A
Organization flags/emblems go in the identity slot at 52×34px — same as national flag treatment. Option A (identity slot) chosen over Option B (muted background) and Option C (dedicated right panel). Every NGE page gets an emblem in this slot. Pattern generalizes to all entity types with official visual marks.Locked
NEWIran canonical page renamed
fora_iran_hybrid.html → fora_jurisdiction_iran.html. The toggle page (fora_jurisdiction_iran_toggle.html) is archived — the hybrid/single-page format is canonical. All future Iran work goes to fora_jurisdiction_iran.html.Locked
NEWGaza / Hamas — Option 3
Two separate pages. fora_jurisdiction_gaza.html = the territory and 2.1–2.2M people. fora_nge_hamas.html = the organization (political bureau, military wing, funding, relationships, designations). Hamas chip in Gaza hero-right links to Hamas NGE page. Hamas org page has blue info banner linking to Gaza jurisdiction page. Hamas breadcrumb: The World / Palestinian Territories / Gaza Strip / Non-Governmental Entities / Hamas — Organization.Locked
NEWDiscourse tab system
Comments live in Discourse tab only (not inline). Every piece of information is up for debate. Comments sorted by upvotes — most popular rise. Psych analysis on every comment shown to all readers. User sees own psych mirror before posting with Revise / Post as written. Canonical civic marker (ring + credential pill) for user identity — no names, no invented role badges. Three-round deliberation (72h each). Vote: 60% of anyone who opened the modal (lowest eligibility bar). Last editor has right of first response in Round 2. Moderator veto as final circuit breaker.Locked
NEWAmendment ratification threshold
60% of the eligible pool (anyone who opened the modal). Not 60% of voters — 60% of interested parties. This makes amendments on high-traffic contested content harder to pass than obscure sections, which is correct. Pool denominator = anyone who opened the modal (lowest bar). Vote opens only after all 3 deliberation rounds complete. Moderator may ratify, reject, or reopen deliberation after vote closes.Locked
NEWPopulation figure corrected
Pre-war Gaza population corrected from 2.3M (UN OCHA projection) to 2.1–2.2M (PCBS 2022 census authority + CIA World Factbook). Applied across all 6 instances on the Gaza page: hero stat, sidebar, body text, CivicIssues, displacement modal cards, stat-pop modal body.Locked
LOCK7 canonical tabs
Overview · Active Crisis ● · Government · Foreign Affairs · Doctrine & History · Discourse · The Record. Every jurisdiction uses these 7. Active Crisis is conditional. Sub-national jurisdictions adapt labels (e.g. "Zoning & Land Use" replaces "Foreign Affairs" at city scale). Hover tooltip shows the civic question.Locked v8
