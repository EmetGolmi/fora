Locked Decisions
All decisions from sessions v8–v12 remain locked. New decisions from this session marked NEW.
DecisionWhat was decidedStatus
NEWNav structure — final
Dashboard · Legislation · Issues · Events · Discourse. Feed dropped as top-level nav — surfaces as "See all" from the Civic Feed dashboard widget. Commonwealth naming (The Commons, The Lyceum, The Ledger, The Square) permanently retired — not referenced anywhere in FORA. Discourse elevated to top-level tab, replacing Feed.Locked
NEWNavigation model — Option C
Top nav for sections (Dashboard · Legislation · Issues · Events · Discourse). Left sidebar for personal items only (identity anchor, My FORA, Following). Sidebar collapses on content pages to restore full width. Three options were mocked up (A: top only, B: left only, C: both). Option C selected.Locked
NEWDashboard — free-form widget grid
12-column CSS grid, 60px row units. Drag to move in customize mode. Edge/corner drag to resize at any time (not gated by customize mode). 14 widgets at launch: Civic Feed, My Representatives, Rep Activity, Active Deliberations, Duel Arena, Bills Tracking, Civic Marker (3 scales), Avatar Card, Civic Stats, Freedom & Happiness, Trending, My Jurisdictions, People (→ The Living), Notes. Widget picker slide-in panel. Customize mode shows drag handles and reveals Add Widget button.Locked
NEWBills Tracking widget — country flag
Country flag emoji sits left of each bill in the Bills Tracking widget and the Legislation page BillCard. Supports multi-country bill tracking. US, UK, Canadian, Cuban bills all render with their respective flag.Locked
NEWNotes widget
Free-text research workspace on the dashboard. Formatting toolbar (Bold, Italic, Underline, Bullet, Link, @ page-tag, " cite-source). Character count. "Share with community ↗" button routes to discourse contribution flow — attaches note to a specific page section or starts a new thread. Note content stored on DashboardWidget.config — not a separate entity.Locked
NEWFollowing sidebar — expanded
Four subsections: Places (jurisdictions), Topics (civic issues), Organizations (NGEs), People. "+" Follow button at the bottom covers all four types. People subsection shows officials and registered users. The Living subsection behavior described separately below.Locked
NEWThe Living
The sidebar subsection starts as "People" for every user. It renames to "The Living" — for that user only — the first time they follow a non-human entity (zoo animal, sanctuary resident, tracked wildlife). The Living divider appears in the People widget between human and animal follows. A greyed placeholder ("No animals followed yet — zoo and sanctuary residents with FORA pages will appear here") shows before first animal follow. FORA recognizes animals as civic stakeholders in specific legal contexts (Endangered Species Act, diplomatic loans, national park management). FORAnimal entity in ERD handles animal pages with livestream URLs and civic_context fields.Locked
NEWLegislation page layout
Two columns. Left: bills the user is tracking, grouped by scale (Federal → State → City), each group collapsible. Right: discovery column — bills FORA has identified as relevant to the user's profile but not yet tracked. Each BillCard has flag, bill ID, title, status chip, scale chip, relevance note explaining why it's surfaced, and Track / Tracked / Discuss / Full text action buttons.Locked
NEWIssues page layout
Left panel: topic cards with jurisdiction-scale chips (Women's Rights → Iran / USA / TX / CA / VA / Gaza). Right panel: detail view showing the same issue at every scale the user follows — status, condition chips, FORA contribution count. Jurisdictions the user doesn't follow are visible but greyed with "Follow [place] to engage." Topic pages at nested jurisdiction scales (full Women's Rights → Iran deep-dive) is a separate content type — tabled for its own session.Locked
NEWEvents page layout
Month calendar with color-coded event pips (blue=civic/federal, green=community, scarlet=FORA events, amber=deadlines, purple=discourse). Jurisdiction filter chips above calendar — toggle places on/off. Day/Week/Month toggle. Daily digest right panel showing today's and tomorrow's events across all followed places. Philadelphia in following → Philly events (St. Patrick's Day parade, Flower Show) appear in digest. Community events (festivals, parades) = v2 pending data partnership. Launch = civic calendar only.Locked
NEWDiscourse page layout
Single column sorted by urgency (time_remaining ASC). Left border color encodes urgency tier: Critical (scarlet), High (amber), Active (blue), Watching (grey). Each item: countdown timer, type badge (Vote closing / Duel · Your turn / Deliberation · Round N / Deliberation · Your proposal / Duel · Watching), page reference, plain-language description of current state, context chips, action button (Cast vote / Respond now / Add rebuttal / View thread / Watch). Right rail: personal discourse stats + live platform activity counts with pulse animation.Locked
NEWCultural Page — architecture
New content type. Cultural pages live inside jurisdiction pages under a Culture section. Canonical home: [Country] › Culture › [Holiday]. NOT a standalone top-level entity. St. Patrick's Day canonical home: Ireland › Culture › St. Patrick's Day. Global celebrations cross-link: each city's jurisdiction page links to the canonical cultural page; the canonical page aggregates all cross-links with a world map hero and place cards. FORA seeds editorially. Community expands through standard amendment process. Cross-linked from the Events calendar — clicking a cultural event pip opens the cultural page.Locked
NEWCultural Page — content structure
Eight tabs: Celebrations (SVG world map with pins + place cards), History (narrative + timeline), Food & Drink (food grid with authenticity notes), Traditions (tradition items with icons), Etiquette (Do / Don't items), Civic Context (contested civic dimensions of the holiday), People (historical and contemporary figures), Discourse. Hero: gradient, holiday icon, English + local-language name, stats bar (countries, diaspora, years, first notable date). Date badge and origin card float right.Locked
NEWCultural Page — map hero
SVG world map with green pins for major celebrations, gold pin for user's followed cities (Philadelphia starred as "You follow Philly"). Click any pin → city celebration summary. Place cards below map: each city gets a card with hero color, flag, place name, scale, description, tradition chips, distinctive detail, FORA cross-link. Canonical origin city (Dublin) gets "Origin · Canonical" badge. User's followed cities get gold border and "★ You follow [city]" badge.Locked
NEWCultural Page — civic context tab
The Civic Context tab holds the contested civic dimensions of every holiday — not just celebration content. St. Patrick's Day prototype includes: NYC LGBTQ parade exclusion (1991–2015), Irish immigration and "No Irish Need Apply" nativism, The Troubles and Northern Ireland, Boston Irish-American political machine. FORA describes, does not decree — same principle as jurisdiction pages and NGE pages. Each civic item links to the discourse tab.Locked
NEWERD v16 — pending
Four new entities from the Cultural Layer: CulturalEvent, CultureSection (1:1 with Jurisdiction), CulturalEventJurisdiction (many-to-many cross-link), CulturalEventContent (one row per tab per event). All four fully specced in Spreadsheet §20. ERD v16 HTML file not yet built — immediate next step.Spec locked · ERD pending

Design
The Duel — wireframe
All discourse system decisions locked since v11. Still no wireframe for The Duel experience itself: proposition, two-user structure, round format (Opening · Rebuttal · Cross · Closing), AI fact-checking in real time, community scoring, how it opens from a content page. Most FORA-original feature on the platform. Recommended next design session.
Design
Lebanon jurisdiction page
Most ready next jurisdiction build. Cross-links to Iran, Hezbollah, and Quds Force all exist and are waiting. Structurally identical to Iran — same layout, same tab system, same trajectory mechanic. Hezbollah-Lebanon relationship is the primary civic complexity.
Design
Houthis NGE page
Tickered on Iran, Gaza, and Hamas pages with no destination. Every tick is a broken promise. Yemen jurisdiction page is the natural companion.
Design
Mobile entry flow — Section D dual-path update
fora_entry_flow.html still has the old 10-category occupation grid. Needs the dual-path system (AI interpreter + 22-sector + BLS SOC) adapted for single-column mobile layout.
Dev
Credential verification backend
Entry flow and ERD fully specced (CivicCredential entity). Connections to NCEES, state bar registries, NPI, AFL-CIO directories not yet built. Gold ring cannot function without this. Can launch with graceful degradation (credential submitted, verification pending).
Dev
Address-to-representative assignment
Entry flow collects address with HAVA/NVRA explanation. Google Civic Information API (or equivalent) connection not built. Without it, representative stack is empty after onboarding.
Dev
BLS SOC data seed — 867 occupations
Onboarding SOC search uses a ~35-entry HTML subset. Production requires importing full BLS SOC 2018 dataset into SOCOccupation table, mapped to CivilizationSector IDs with US worker counts from OEWS. Static dataset — seed once, update on BLS revision cycle.
Org
Editorial Board composition
Community Standards references the Editorial Board 11 times. Needs to exist on paper with composition published in first Transparency Report before contested jurisdiction pages (Iran, Gaza) go live.
Org
Legal review — all three documents
Privacy Policy, Community Standards, Terms of Service are confidential drafts. All three must be reviewed before any user sees them. Key areas: Delaware corporate law, Section 230, AAA arbitration enforceability, COPPA, DMCA designated agent, registered agent in Delaware. Three placeholders remain: effective date, DMCA agent contact, registered agent.
Org
Cookie policy / consent banner
Required before any analytics are added. Even a minimal disclosure. Should be drafted and reviewed alongside the three main legal documents.
Tabled
Topic pages at nested jurisdiction scales
Women's Rights → Iran / USA / TX / CA — a new content type between Issues and Cultural pages. Needs its own session. The Issues page currently shows the issue at each scale as cards; full topic pages with their own discourse systems are a separate architectural decision.
Tabled
Comparison widget + share findings
Tabled from the dashboard session. Touches the discourse system, sharing infrastructure, and potentially a new widget type. Needs its own session once the core discourse wireframe (The Duel) is complete.
Tabled
Community Events integration
Events page is civic calendar only at launch. Philly Flower Show, St. Patrick's parade, festivals require data partnership with Eventbrite or equivalent. v2 feature.
