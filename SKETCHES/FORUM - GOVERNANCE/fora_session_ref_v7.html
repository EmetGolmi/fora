Architecture · Canonical

Locked Decisions

These are not open for reconsideration. Build against them.

Locked
Platform name
FORA. All caps. The agora without the A. Civic square. Not Forum Americanum in UI — that's the internal codename.
Locked
Four named sections
The Commons · The Lyceum · The Ledger · The Square. /square/civics houses Bill Intelligence Dashboard and zoning/civic issue tracking.
Locked
"Effort" = civic campaign
The word for organized civic campaigns within FORA. Not "petition," not "campaign," not "initiative." Effort. Everywhere.
Locked
local_label field
Makes FORA jurisdiction-aware. RCO in Philadelphia · Community Board in NYC · ANC in DC. Same schema, different label per jurisdiction. Never hardcoded.
Locked
Variant 1 = canonical
Civic Charter. fora_variant_1.html is the canonical component reference. Variants 2 and 3 retired. All new screens build from Variant 1 tokens.
Locked
Address entry flow
Zip code only (not full address). Federal + state free. Local unlocked with street address. 4-stage: ask → reveal → hook → save. Create profile or browse anonymously CTAs.
Locked
Congress.gov API integer format
119 (integer, not string) for all Congress.gov API calls. Numeric congress number, never "119th" in API parameters.
Locked
FORA's job
Build the shared description. Not the solution. The Scientific Method as platform architecture: every CivicEvent maps to 7 stages (Observation → Communication). FORA does not adjudicate — it describes.
Locked
NGE photo rules
Turban silhouette = Khamenei successor only (unknown cleric). Plain silhouette = no public photo / organizational entities. Real photo via corsproxy = all known named individuals. No initials fallback for known people.
Locked
Death badge for Muslim figures
🪦 tombstone (not ✝ cross). Active Muslim leaders: ☪ crescent. Catholic figures: ✝. Jewish figures: ✡. Death badge: 🪦 universal regardless of religion.
Locked
NGE section header plain language
"What they call themselves — and what others call them." Never "endonym/exonym" in UI.
New v6
Zoning — out of scope language
Building materials, aesthetics, construction logistics (dumpsters, cranes, noise, duration) are out of scope at the BVNA zoning meeting. Construction permits (dumpster, equipment placement, crane) use "may apply" language — not "required." FORA is not a legal authority.
New v6
Zoning case folder = full dossier
Each zoning case address links to a dedicated case folder page containing: embedded Google Map, OPA property stats, all Philly city system links (Atlas tabs, ZBA calendar), process timeline, document submission tracker, BVNA position, construction permit tips. Not just Google Maps.
New v6
Notification mailer → FORA targeting
The PCPC near-neighbor mailed notice (250 ft radius) is replaced by geo-targeted FORA push notifications for registered users. Physical USPS mailer remains as backup for non-FORA residents only. FORA surfaces "You're within 250 ft — FORA has notified you in lieu of mailed notice."
New v7
Jurisdiction page = governing philosophy home
A state's governing philosophy lives on its jurisdiction page as a structural/constitutional description — factual, neutral, same treatment as any government's structure. The Islamic Republic's Velayat-e Faqih gets the same container as US constitutional republicanism or Cuban Marxist-Leninism. No special NGE-style page needed for ideology.
New v7
CivicIssue = contested ideology container
The theological/philosophical questions behind a governing doctrine live as CivicIssues — persistent contested questions FORA describes but doesn't resolve. "Is Velayat-e Faqih legitimate?" and "Is liberal democracy a universal value?" are both CivicIssues. FORA holds the disagreement without adjudicating.
New v7
US exports theology too
American exceptionalism, liberal democratic capitalism, soft power (jazz, hip-hop, NGOs, democracy promotion) are a theology — not called that by its practitioners. FORA treats US ideological exports symmetrically with Iranian ones. Same jurisdiction page structure, same CivicIssue container for contested questions. The endonym/exonym gap is the measurement of trajectory.
New v7
Newspaper layout = reading view for jurisdictions
Explored in fora_jurisdiction_iran_newspaper.html. Dashboard = reference view (looking something up). Newspaper = reading view (understanding something). Jurisdiction pages may warrant reading view as default — countries are stories, not just data. Decision pending: universal pattern vs. mode toggle.
New v7
Trajectory removed from Overview tab
Historical trajectory is its own tab on jurisdiction pages, not part of Overview. Overview = Active crisis + Government structure + Governing philosophy + NGE relations + CivicIssues. Trajectory tab carries the full arc with endonym/exonym divergence at each inflection point.
