X / Twitter
Black pill, white text. No icon. Single word. Becomes outlined "Following" when active. Most copied pattern on the web.
Accessibility: High contrast, clear state change
Instagram
Blue text, white background, light border. Rectangular with rounded corners. Becomes "Following" in gray when active. More subtle than X.
Accessibility: Color alone doesn't indicate state — needs text change
LinkedIn
Outlined blue pill with + icon. Icon provides additional affordance. LinkedIn uses this for both people and companies. Very legible.
Accessibility: Icon + text redundancy is best practice
GitHub
Subtle, secondary-style button. No color emphasis — fits GitHub's minimal aesthetic. Icon establishes context without demanding attention.
Accessibility: Very WCAG compliant — never relies on color alone
Spotify
Outlined white on dark. Compact. On light backgrounds becomes outlined dark. Spotify uses this for artists — feels personal, not institutional.
Accessibility: Works on dark only — needs inversion on light
YouTube
YouTube calls it "Subscribe" not "Follow" — the verb signals ongoing relationship. After subscribing it adds a bell. The action communicates commitment.
Accessibility: Icon + label + state change on click = ideal pattern
