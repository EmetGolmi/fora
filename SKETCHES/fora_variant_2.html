♿
Accessibility note on source labels: You raised a valid concern about pill-shaped static labels creating button affordance. Per WCAG 2.1 SC 1.4.1 and ISO 9241-171:2008 §9.3.14, interactive and non-interactive elements must be visually distinguishable beyond color alone. This set resolves that with a left-rule square tag — border-radius: 3px, no hover cursor, JetBrains Mono label treatment. It reads as metadata, not a button.

Accessibility Resolution — unchanged
WCAG 2.1 SC 1.4.1 (Use of Color) — interactive/non-interactive distinction must not rely on color alone.
WAI-ARIA Authoring Practices — buttons require role="button" or <button>; static labels should never share that visual language.
ISO 9241-171:2008 §9.3.14 — "Interactive and non-interactive elements should be visually distinguishable."

Resolution: Left-rule square tag (border-radius: 3px, cursor: default, border-left: 4px solid for semantic colour, colour dot as secondary signal, full-word label in JetBrains Mono).
